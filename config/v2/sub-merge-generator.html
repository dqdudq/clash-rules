订阅合并链接生成器

粘几个机场订阅链接，选规则模板，生成一条 sub.dqhub.uk 合并订阅链接。粘进 OpenClash / Clash Verge 的订阅框即可，节点、分组、分流规则一次到位。全程本地运算，链接不外发。

输入

本地运算 · 不联网
机场订阅

名字只用于你自己辨认，不进链接。多个机场按顺序合并；subconverter 无法按机场分优先级，「地区优选」靠节点名里的 E-/S- 档前缀筛。

目标格式
过滤掉的假节点关键词

机场常把「剩余流量 / 到期日 / 官网」塞成假节点。命中这里任一关键词的节点会被丢弃。

选项
合并订阅链接

填机场链接，点「生成链接」。

怎么用
  1. 复制上面的链接
  2. OpenClash → 配置订阅 → 新增，地址粘进去；或 Clash Verge → 订阅 → 新建
  3. 更新订阅 → 选中生成的配置 → 应用
  4. 之后换机场链接：回本页改 → 重新生成 → 覆盖那条订阅地址即可
链接里带各机场 token，等同订阅链接本身。别公开发、别贴进公开仓库。
